How this is worked out

What the archives do

The Internet Archive's Wayback Machine (web.archive.org) keeps dated copies of web pages, made by its own crawlers and on request. Each copy has a 14-digit timestamp, YYYYMMDDhhmmss in UTC: 20261126140509 is 26 November 2026 at 14:05:09 UTC, the moment the archive fetched the page. archive.today (archive.ph) is a separate, independently run archive that also saves a copy on request and keeps a screenshot of it.

Checking for a copy

"Check the Wayback Machine" asks the Internet Archive's availability API, archive.org/wayback/available?url=…&timestamp=…, for the copy nearest your time (or the most recent copy when you give no time). The answer names the copy's address, its timestamp and the HTTP status the site gave when it was fetched (200 means the page was there; 404, not found; 301 or 302, a redirect to somewhere else, so open the copy and check what it shows). The API looks only at copies of that exact address, and it sometimes answers "none" when copies exist; the "all Wayback copies" link opens the archive's own calendar to check.

Asking for a new copy

"Save a new copy" only opens the Internet Archive's Save Page Now page for the address in a new tab; this page sends nothing itself and uses no key. The archive may ask you to press a button or sign in, and can take a minute. The archive.today link opens its form with the address filled in for you to submit; it often asks you to prove you are a person. Neither archive is run by this toolbox.

What to know before relying on a copy

  • A copy is public. Anyone can find it by the page's address, and the site's owners can see that it was archived.
  • Your request is seen. The Internet Archive (or archive.today) learns the address you asked about, and when you save a copy the site receives a request from the archive.
  • Some sites block archiving (by robots.txt rules, by refusing the archive's crawler, or by asking for copies to be withdrawn), and pages behind a login, a paywall, or built by scripts may be saved blank or incomplete. Open the copy and check that it shows what you need.
  • A copy can be removed later at the site owner's request. For anything important, keep your own copy too (a saved page file or screenshots), and note the time.
  • This is a record of what an archive saw, not a forensic chain of custody. The archive's timestamp is when its crawler fetched the page; what the page showed to other visitors, regions or devices can differ.

The address

The address is cleaned before it is sent: https:// is added when you give none, only http and https are allowed, an address with a user name or password in it is refused (it would be sent to the archive), private and local addresses (such as 192.168.x.x or localhost) are refused because a public archive cannot reach them, and the fragment after # is dropped. The path and query are kept exactly, since a different query can be a different page; remove tracking parameters yourself if you do not want them recorded.

The log and its exports

Each log entry holds the page address, the time you checked or recorded it (UTC), the archived copy's address and timestamp, how it was recorded, your note and a citation line:

“Title.” Page URL. Archived by Archive, captured YYYY-MM-DD hh:mm:ss UTC: archived URL. Checked YYYY-MM-DD hh:mm:ss UTC.

CSV follows RFC 4180 (values with commas, quotes or line breaks in double quotes, UTF-8, CRLF line ends). A value that starts with =, +, -, @ or a tab gets a leading apostrophe so that a spreadsheet shows it as text instead of running it as a formula; JSON keeps the values exactly.

Services and their terms

Internet Archive Wayback Machine availability API and Save Page Now: free, no key; use is under the Internet Archive's terms of use, and its availability API is called from your browser only when you press the button. archive.today: free, run independently; this page only links to it. If the availability API refuses the request from the browser, the page says so and gives the request as a link to open yourself.

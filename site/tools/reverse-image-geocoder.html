Reverse Image Geocoder

Puts a photo on the map from the GPS position its camera or phone wrote into the file's EXIF metadata, with the direction the camera faced when that was recorded. It reads coordinates only; it does not look up a street address. The photo is read in this browser and is never uploaded.

Choose a file or drop one on this panel. EXIF is read from JPEG files only.

Search for the photo elsewhere

Reverse-image search sites look for other copies of a picture. These are plain links to each site's own upload page: this page sends them nothing. If you upload the photo there, it goes to that company, and the original file carries its GPS position and other metadata with it. To avoid that, make a copy without metadata first (the picture is redrawn in this browser and saved as a new JPEG, slightly recompressed).

    How this is worked out

    The file is read in the browser and its EXIF block parsed by Exif.js (exif-js 2.3.0, MIT licence). The GPS latitude and longitude are stored as degrees, minutes and seconds with a separate hemisphere letter; decimal degrees = degrees + minutes ÷ 60 + seconds ÷ 3600, negative for south and west. Altitude is negative when the file says below sea level. The GPS time stamp is UTC by definition and is shown in your chosen time zone; the camera's own "taken" time has no time zone and is shown exactly as written.

    When the photo records the direction the camera faced (GPSImgDirection) against true north, a 300 m line is drawn that way: the end point is the destination point along a great circle, lat₂ = asin(sin lat₁ cos δ + cos lat₁ sin δ cos θ), with δ = distance ÷ 6,371 km. A direction against magnetic north is listed but not drawn, because the photo does not record the local magnetic declination (the angle between magnetic and true north).

    Limits. Metadata is easy to edit, strip or forge: the position is a lead to check against the picture itself, not proof. A phone's fix can be tens of metres out, more indoors or when the fix was stale. A position of exactly 0, 0, a missing hemisphere letter or a datum other than WGS 84 is flagged. Network use: map tiles from OpenStreetMap (tile.openstreetmap.org), Leaflet from unpkg.com and Exif.js from cdn.jsdelivr.net. The map and search links open other sites only when you follow them; a map link sends that site the coordinates.

    References: CIPA DC-008, Exif Version 2.32, section 4.6.6 (GPS tags); Chris Veness, "Calculate distance, bearing and more between latitude/longitude points", movable-type.co.uk (destination point). Test: tests/image-geocode.test.js (from 53° 19′ 14″ N, 001° 43′ 47″ W on 096° 01′ 18″ for 124.8 km: 53° 11′ 18″ N, 000° 08′ 00″ E).

KML/KMZ Visualizer

Opens a KML file (the map format Google Earth saves) or a KMZ (a zipped KML) on a map: its points, lines and polygons, grouped by folder, with each line's length and each polygon's perimeter and area. The file is read in this browser and is never uploaded.

Choose a file or drop one on this panel.

The JSON is GeoJSON (RFC 7946), which most mapping and GIS software opens.

Features

How this is worked out

A KMZ is unzipped in the browser with JSZip (3.10.1, MIT licence) and its main KML chosen: doc.kml at the top level, else the first KML there. The KML is read with the browser's own XML parser. Every Placemark becomes one feature per geometry: Point, LineString, LinearRing, Polygon (an outer boundary and any holes), each part of a MultiGeometry, and Google's gx:Track. KML writes each position longitude first, as longitude,latitude[,altitude] in decimal degrees on WGS 84; a position out of range (often a file written latitude first) is reported and that geometry skipped. A ring that does not end where it starts is closed.

Lengths and perimeters add up great-circle distances between consecutive positions with the haversine formula on a sphere of radius 6,371 km. Polygon area is A = (R² ⁄ 2) · |Σ (λi+1 − λi−1) sin φi| over the ring's positions (λ longitude, φ latitude, in radians), less the area of any holes.

Limits. A sphere, not the WGS 84 ellipsoid: lengths and areas can differ from an ellipsoidal calculation by up to about 0.5%. The area formula treats each edge as a straight line on an equal-area cylindrical map (exact for edges along parallels and meridians); for edges of up to a few hundred kilometres that is very close to the great-circle edge. Altitudes are kept in the JSON but not used in the measures. Styles, icons, overlays, 3D models and time spans are not drawn, and network links (KML that loads other files from the internet) are counted but not followed. Descriptions are shown as plain text; nothing in a file is run or fetched. The map draws straight lines between positions on a flat Web Mercator map, so a long, sparse line looks different from Google Earth's globe. Network use: OpenStreetMap map tiles (tile.openstreetmap.org), Leaflet from unpkg.com and JSZip from cdnjs.cloudflare.com. The last file's features are kept in this browser so they come back on your next visit; Clear removes them.

References: OGC KML 2.2 (OGC 07-147r2), sections 16.9 (coordinates), 10.8 (Polygon) and 10.5 (LinearRing); RFC 7946 (GeoJSON); Chris Veness, "Calculate distance, bearing and more between latitude/longitude points", movable-type.co.uk (haversine); Chamberlain and Duquette, "Some algorithms for polygons on a sphere", JPL Publication 07-03, 2007 (area). Test: tests/kml.test.js (a 1° × 1° cell from the equator: 12,363.68 km², perimeter 444.763 km).

Image Metadata Extractor

Reads the EXIF block (the data a camera or phone writes inside a photo file) from a JPEG: where it was taken if the device recorded a GPS position, when by the camera's own clock, and the camera and exposure settings. The photo is read in this browser and is never uploaded.

Choose a file or drop one on this panel. EXIF is read from JPEG files only; other formats are shown but their metadata is not read.

Nothing leaves this page: the file is read with the browser's own file reader. Many sites (messaging apps, social networks) strip EXIF when a photo is shared, so a photo saved from one often has none.

How this is worked out

The file's bytes are read in the browser and parsed by Exif.js (exif-js 2.3.0, MIT licence), which finds the EXIF block in a JPEG and returns each tag. This page turns those tags into figures following the Exif standard:

  • Position. GPS latitude and longitude are stored as degrees, minutes and seconds with a separate letter for the hemisphere. Decimal degrees = degrees + minutes ÷ 60 + seconds ÷ 3600, negative for south (S) and west (W). Altitude is negative when the altitude reference says below sea level. A position of exactly 0, 0, a missing hemisphere letter, or a map datum other than WGS 84 (the datum web maps use) is flagged.
  • Times. The "taken" and "modified" dates are the camera clock's reading, written as year:month:day hour:minute:second with no time zone, so they are shown exactly as written and not converted. Only the GPS date and time stamp is defined as UTC, so only it is shown in your chosen time zone. When both are present the page gives the difference between them: a hint at the offset the camera clock was set to, if both clocks were right, not a recorded time zone.
  • Flash is a set of bits (fired or not, mode, return light, red-eye); exposure time is shown as a fraction (1/250 s) when it is one.

Limits. Metadata is easy to edit, strip or forge, so treat it as a lead to check, not proof. A phone's GPS fix can be tens of metres out (more indoors), or old if the fix was stale. Exif.js does not read the Exif 2.31 time-offset tags, maker notes, XMP, PNG, HEIC or WebP metadata. The map links open OpenStreetMap or Google Maps in a new tab and send them the coordinates in the link; nothing is sent unless you follow one. The only other request this page makes is to load Exif.js from cdn.jsdelivr.net.

Reference: CIPA DC-008, Exchangeable image file format for digital still cameras: Exif Version 2.32, sections 4.6.5 (Exif tags) and 4.6.6 (GPS tags). Test: tests/image-metadata.test.js (40° 26′ 46.302″ N, 79° 58′ 56.484″ W gives 40.446195, −79.982357).

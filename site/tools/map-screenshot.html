Geography and mapping

Map Screenshot

Saves the map view as an image file for a report or briefing. The image carries a title and notes above the map, any labelled markers you place, and below it a scale bar (a line of known ground length), the centre position, the capture time in UTC and the map credit.

View

Decimal degrees, north and east positive. Each zoom step halves the ground shown. Panning or zooming the map updates these boxes.

How this is worked out

The map uses OpenStreetMap's 256-pixel tiles on the Web Mercator projection (the square world map most web maps use). One screen pixel covers this much ground along the parallel at latitude φ and zoom z:

metres per pixel = 156,543.03392 × cos φ / 2z

where 156,543.03392 m is the Earth's equator (2π × 6,378,137 m, the WGS 84 equatorial radius) spread over one 256-pixel tile at zoom 0. The scale bar is the longest round length (1, 2 or 5 times a power of ten) that fits in 200 screen pixels at the latitude of the map centre. The scale ratio (1:N) assumes the CSS reference pixel of 1/96 inch; a printed copy has whatever scale its print size gives it.

Limits. Web Mercator stretches the map by 1 / cos φ, so the ground scale is only right near the centre latitude: the results show it at the top and bottom of the view and how much it changes. At zoom 4 or less a scale bar can be badly wrong at the edges; the image then still carries one, so read it at the centre only. The capture is a copy of the page made by the html2canvas library (1.4.1), not a print-quality render, and a marker label or tile edge can shift by a pixel. Map tiles come from OpenStreetMap (tile.openstreetmap.org), which lets pages copy its tiles into an image; tiles from a server that does not send that permission (a CORS header) would block the capture. Nothing else is fetched, the image is made in your browser, and your inputs are kept only in this browser.

Reference: OpenStreetMap wiki, "Zoom levels" (metres per pixel); W3C, CSS Values and Units, absolute lengths (1 px = 1/96 in). Test: tests/map-screenshot.test.js (latitude 38°, zoom 8: 481.87 m per pixel; equator, zoom 18: 0.5972 m).

Dead Drop Toolbox. Everything runs in your browser; the only request it makes is for OpenStreetMap map tiles.

ICAO Address Decoder

Every aircraft transponder that answers Mode S radar interrogations, and every ADS-B transmitter (the broadcast that flight-tracking sites pick up), sends a fixed 24-bit number, the ICAO aircraft address, usually written as six hexadecimal characters such as A061D9. The country that registers the aircraft (the state of registry) assigns it from a block ICAO gives that country. This page says which block an address is in and, for US addresses, turns the address into the aircraft's registration mark (its N-number) and back. The address names a registration block, not an aircraft type, owner or role, and it can be wrong: transponders are sometimes set up with the wrong address, and a transmitter can be made to send any address at all.

Address or N-number

Six hexadecimal characters (0-9, A-F), with or without 0x, or a US N-number such as N12345. Up to 500 lines.

    How this is worked out

    What the address is. The ICAO aircraft address is a 24-bit number (16,777,214 usable values) assigned to one airframe by its state of registry. Mode S radar uses it to call one aircraft at a time, ADS-B sends it with every position report, and airborne collision-avoidance systems use it to tell aircraft apart. It stays with the airframe, usually even when the aircraft's flight number changes; it normally changes when the aircraft moves to another country's register.

    State of registry. ICAO Annex 10, Volume III, Part I, Chapter 9, Appendix (Table 9-1) gives each state a block of addresses, written there as a fixed run of leading bits. The page looks the address up in that table, transcribed in the page's library as first and last address in hexadecimal. Blocks run from 1,024 addresses (small states) to 1,048,576 (the United States and the Russian Federation). An address outside every block is unallocated or held in reserve. The two blocks ICAO keeps for itself (F00000-F07FFF for temporary addresses and F09000-F093FF for special uses) are labelled as such. ICAO does not assign the all-zeros or all-ones address. Amendments to the Annex re-assign blocks from time to time (for example after a state splits), so check a result that matters against the current edition.

    US N-numbers. The FAA maps US addresses A00001 to ADF7C7 one-to-one onto the 915,399 possible N-numbers, in a fixed order: N1, N1A, N1AA, N1AB ... N1AZ, N1B ... N1ZZ, then N10, N10A, and so on, with the letters I and O never used. Counting N-numbers in that order gives the address directly, and dividing an address back out gives the N-number:

    run(k) = number of N-numbers starting with a k-digit prefix: run(5) = 1, run(4) = 35, run(3) = 951, run(2) = 10,111, run(1) = 101,711

    so N1 = A00001, N2 = A00001 + 101,711 = A18D50, N12345 = A061D9 and N99999 = ADF7C7. The FAA aircraft registry publishes each registered aircraft's code beside its N-number (its "Mode S code", in octal and hexadecimal; the octal form is shown here too). The conversion works whether or not the N-number is currently assigned: an unregistered N-number still has its address, and a decoded N-number may belong to no aircraft today.

    Military blocks. ICAO does not publish military sub-blocks, and states do not either. Ranges that open-source ADS-B software flags are shown only as "community-reported, not ICAO", and the page never states that an aircraft is military. The US range above ADF7C7 is outside the N-number sequence; what uses it is not published.

    Limits. A decoded state is where the address was allocated, which is normally but not always where the aircraft is registered now: an aircraft sold abroad can keep its old address for a while, a transponder can be set up with a wrong or default address, and test equipment or a deliberately altered transmitter can send any address, including one copied from another aircraft. Some aircraft send no ADS-B, or send a temporary or privacy address (the FAA's privacy programme issues addresses not tied to the owner's N-number). Treat the result as one clue to check against the registry, the flight's track and other sources.

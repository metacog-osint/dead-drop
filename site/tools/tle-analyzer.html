Orbits and space

TLE Analyzer

A two-line element set (TLE) is the standard short text that describes a satellite's orbit at one moment, its epoch. This tool reads one field by field, checks its checksums, and works out the orbit's period, size and lowest and highest points. It can also fetch a current element set from CelesTrak and show where the satellite is now.

An optional name line, then line 1 and line 2, exactly as published (69 characters each).
The text holds more than one element set.

Look up at CelesTrak

One request each time you press a button; nothing refreshes on its own. A name search matches every satellite whose name contains the text.

How this is worked out

The fields are read from fixed columns as CelesTrak's format notes and Spacetrack Report No. 3 set them out. Eccentricity and the two exponent fields carry an implied leading decimal point (-11606-4 is −0.11606 × 10−4). The two-digit epoch year means 1957–1999 for 57–99 and 2000–2056 for 00–56; the epoch day counts from 1.0 at 00:00 UTC on 1 January. Catalog numbers above 99999 use the Alpha-5 form, a letter for the first digit (A = 10, I and O skipped). The checksum in column 69 is the sum of the digits in columns 1–68, counting each minus sign as 1, modulo 10; a mismatch usually means a mistyped character.

The mean motion n (revolutions per day) gives the period, 1440 / n minutes, and by Kepler's third law the semi-major axis a (half the long axis of the orbit's ellipse):

a = (μ / n²)1/3, n in rad/s, μ = 398600.4418 km³/s²    perigee = a(1 − e) − 6378.137 km    apogee = a(1 + e) − 6378.137 km

Perigee and apogee are the lowest and highest points of the orbit, here measured above the Earth's equatorial radius, not above the ground below. A TLE's mean motion is an SGP4 mean value, not an osculating (instantaneous) one, so these heights are good to a few kilometres and the satellite's actual height wanders around them.

"Where it is now" runs the SGP4 model (satellite.js 5.0.0, MIT licence) from the element set to the moment you pressed Analyze. SGP4 gives the position in the TEME frame (true equator, mean equinox), an Earth-centred frame that does not turn with the Earth; it is turned to the Earth-fixed frame through Greenwich mean sidereal time (IAU-82) to give the point below the satellite and its height above the WGS 84 ellipsoid. SGP4's error is about a kilometre at the epoch and grows with time from it, typically by one to a few kilometres a day for low orbits (a rough guide; it depends on the orbit and on solar activity), so the warning after 7 days is a rule of thumb, not a precise limit. The classification letter is U for unclassified in every public element set.

Network: the only request this page makes with what you type is a CelesTrak lookup you start (celestrak.org/NORAD/elements/gp.php). CelesTrak updates its element sets about every two hours and asks users not to fetch the same data more often, so the page asks once per lookup, never on a timer, and reuses an answer to the same query for two hours while the page is open. CelesTrak redistributes element sets published by the US Space Force on Space-Track.org.

References: CelesTrak, "NORAD Two-Line Element Set Format"; Hoots and Roehrich, Spacetrack Report No. 3 (1980); Vallado, Fundamentals of Astrodynamics and Applications, 4th ed., sections 2.2–2.3 and 3.5. Test: tests/tle-analyzer.test.js (the ISS example set: epoch 20 Sep 2008 12:25:40 UTC, period 91.60 min, perigee 348.3 km, apogee 357.3 km; Vanguard 1, 00005: a = 8632.5 km).
